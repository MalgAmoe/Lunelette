# Reference validation artifact index

Independent Transformers CPU FP32 reference fixtures **were generated previously** and used by the optional C comparators. Those external outputs, generation scripts, environments and experiment records are not bundled in this directory. This is an index, not a bundled Python harness or a claim of end-to-end reproducibility. No installation, download or fixture generation is performed by default tests.

Run all documented commands from the repository root. Supply explicit paths to weights and fixtures; repository-local ignored `models/` and `fixtures/` paths in examples are placeholders, not required bundled assets.

Current maintained consumers require **fresh fixtures from the official HF-layout FP8 checkpoint**, not the archived BF16 oracles. FP32 weight reconstruction must multiply decoded E4M3 by widened BF16 weight_scale_inv without BF16 rounding. Validate but do not use activation_scale. Include true cached-decode trajectories, not full-prefix replays; see [current validation](../../docs/validation.md).

## Maintained consumers and contracts

| Optional consumer | Schema, commands and evidence |
|---|---|
| `compare_embeddings`, `make integration` | [Embedding bit comparison](../../docs/validation.md#optional-real-weight-validation) |
| `compare_fp8` | [Exact reconstructed-weight hashes](../../docs/validation.md#current-mixed-checkpoint-validation) |
| `compare_metal` | [Full-model schema and verification](../../docs/validation.md#full-model-reference-comparison) |

CPU projection/attention/block/forward/cache/generation consumers were retired after `4d4f8f8`. Their schemas, numerical findings and strict failures remain historical provenance in the validation guides; external frozen oracles are not removed or regenerated by this migration.

## Required provenance for supplied artifacts

Record the immutable model and tokenizer revisions/files, inspected implementation revision, Python/library versions and build configuration, device, execution dtype, attention mode and thread count. Preserve exact prompts and token IDs, chat-template settings, special-token handling, positions, cache mode and capture points. Document tensor names, shapes, contiguous layout, dtype/endianness, fixture hashes, engine/source/binary identity and exact comparison commands. Use independent reference outputs, not C-derived expected values. Full-depth historical provenance and frozen calibration records are described in the linked guides; their external records are not made available by this index.

Default synthetic tests and comparator match/mismatch/nonfinite self-tests do not replace real-weight comparisons. Bit equality applies to embedding expansion; arithmetic tolerances depend on the capture point and precision. Quantized or other-device execution needs separate evidence. Generate independent references in a separate process from resident Metal weights to avoid memory pressure.
